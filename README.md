# mosaicportal
Mosaic Portal

Mosaic Portal is a web portal for Mosaic Los Angeles.

## Overview

This repository hosts the source code for the Mosaic community portal.

Mosaic Portal is a staff portal that unifies Mosaic's four existing tools —
Communication, Planning, Numbers (Metrics), and Goals — behind one shell, one
visual language, and one login. The portal orients; the existing apps continue
to do the work.
